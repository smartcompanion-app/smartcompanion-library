# Security Policy

## Supported versions

All three packages are released in lockstep. Security fixes are released for the latest minor version. Older versions are not patched.

| Version | Supported |
| ------- | --------- |
| 0.9.x   | Yes       |
| < 0.9   | No        |

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them through [GitHub's private vulnerability reporting](https://github.com/smartcompanion-app/smartcompanion-library/security/advisories/new), or by email to <hello@smartcompanion.app>.

Include the affected package and version, and enough detail to reproduce the issue. You can expect an initial response within a week.
